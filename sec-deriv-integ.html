    Section 2.1 Derivatives and Integrals of Vector Functions

    In this section, we will explore the derivatives and integrals of vector functions, which are essential tools in calculus and physics.
    🔗

    Subsection 2.1.1 Derivatives of Vector Functions

    The derivative \(r'\) of a vector function \(\mathbf{r}\) is defined similar to real-valued functions:
    \begin{equation*} \frac{d\mathbf{r}}{dt} = \mathbf{r'(t)} = \lim_{h \to 0} \frac{\mathbf{r}(t+h) - \mathbf{r}(t)}{h} \end{equation*}
    As with real-valued functions, the derivative of a vector function gives us the rate of change of the vector with respect to the parameter \(t\text{.}\) As \(h \to 0\text{,}\) the difference quotient approaches the derivative, which is a vector that points in the direction of the instantaneous rate of change of \(\mathbf{r}\) at time \(t\text{.}\) For this reason, the vector \(\mathbf{r'(t)}\) is tangent to the curve described by \(\mathbf{r}(t)\) at the point P(\(x(t)\text{,}\) \(y(t)\text{,}\) \(z(t)\)). The unit tangent vector \(\mathbf{T(t)}\) is defined as the normalized derivative of \(\mathbf{r}\text{:}\)
    \begin{equation*} \mathbf{T(t)} = \frac{\mathbf{r'(t)}}{|\mathbf{r'(t)}|} \end{equation*}
    The unit tangent vector points in the direction of the curve at point P and has a magnitude of 1.
    🔗

    Theorem 2.1.1.

    If \(\mathbf{r(t)} = \langle f(t), g(t), h(t) \rangle\) is a vector function, then its derivative is given by:
    \begin{equation*} \mathbf{r'(t)} = \langle f'(t), g'(t), h'(t) \rangle \end{equation*}
    where \(f'(t)\text{,}\) \(g'(t)\text{,}\) and \(h'(t)\) are the derivatives of the component functions of \(\mathbf{r}\text{.}\)
    🔗
    🔗

    Example 2.1.2.

    Let \(\mathbf{r(t)} = \langle t^2, \sin(t), e^t \rangle\text{.}\) Then the derivative of \(\mathbf{r}\) is:
    \begin{equation*} \mathbf{r'(t)} = \langle 2t, \cos(t), e^t \rangle \end{equation*}
    This means that at any point \(t\text{,}\) the rate of change of the vector function is given by the vector \(\langle 2t, \cos(t), e^t \rangle\text{.}\)
    🔗
    🔗

    Example 2.1.3.

    Let \(\mathbf{r(t)} = \langle t^3, \ln(t), \sqrt{t} \rangle\text{.}\) Then the derivative of \(\mathbf{r}\) is:
    \begin{equation*} \mathbf{r'(t)} = \langle 3t^2, \frac{1}{t}, \frac{1}{2\sqrt{t}} \rangle \end{equation*}
    This means that at any point \(t\text{,}\) the rate of change of the vector function is given by the vector \(\langle 3t^2, \frac{1}{t}, \frac{1}{2\sqrt{t}} \rangle\text{.}\)
    🔗
    🔗

    Example 2.1.4.

    Find the unit tangent vector \(\mathbf{T(t)}\) for the vector function \(\mathbf{r(t)} = \langle t^2, \sin(t), e^t \rangle\text{.}\)
    🔗
    Solution.
    First, we find the derivative of \(\mathbf{r(t)}\text{:}\)
    \begin{equation*} \mathbf{r'(t)} = \langle 2t, \cos(t), e^t \rangle \end{equation*}
    Next, we find the magnitude of \(\mathbf{r'(t)}\text{:}\)
    \begin{equation*} |\mathbf{r'(t)}| = \sqrt{(2t)^2 + (\cos(t))^2 + (e^t)^2} = \sqrt{4t^2 + \cos^2(t) + e^{2t}} \end{equation*}
    Finally, we can find the unit tangent vector \(\mathbf{T(t)}\text{:}\)
    \begin{equation*} \mathbf{T(t)} = \frac{\mathbf{r'(t)}}{|\mathbf{r'(t)}|} = \frac{\langle 2t, \cos(t), e^t \rangle}{\sqrt{4t^2 + \cos^2(t) + e^{2t}}} \end{equation*}
    🔗
    🔗
    🔗

    Example 2.1.5.

    For the curve defined by \(\mathbf{r(t)} = \langle t^3, \ln(t), \sqrt{t} \rangle\text{,}\) find the unit tangent vector \(\mathbf{T(t)}\text{.}\)
    🔗
    Solution.
    First, we find the derivative of \(\mathbf{r(t)}\text{:}\)
    \begin{equation*} \mathbf{r'(t)} = \langle 3t^2, \frac{1}{t}, \frac{1}{2\sqrt{t}} \rangle \end{equation*}
    Next, we find the magnitude of \(\mathbf{r'(t)}\text{:}\)
    \begin{equation*} |\mathbf{r'(t)}| = \sqrt{(3t^2)^2 + \left(\frac{1}{t}\right)^2 + \left(\frac{1}{2\sqrt{t}}\right)^2} = \sqrt{9t^4 + \frac{1}{t^2} + \frac{1}{4t}} \end{equation*}
    Finally, we can find the unit tangent vector \(\mathbf{T(t)}\text{:}\)
    \begin{equation*} \mathbf{T(t)} = \frac{\mathbf{r'(t)}}{|\mathbf{r'(t)}|} = \frac{\langle 3t^2, \frac{1}{t}, \frac{1}{2\sqrt{t}} \rangle}{\sqrt{9t^4 + \frac{1}{t^2} + \frac{1}{4t}}} \end{equation*}
    🔗
    🔗
    🔗

    Example 2.1.6.

    Show that if \(\mathbf{r(t)} = \mathbf{c}\) (a constant vector), then \(\mathbf{r'(t)}\) is orthogonal to \(\mathbf{r(t)}\) for all \(t\text{.}\)
    🔗
    Solution.
    If \(\mathbf{r(t)} = \mathbf{c}\text{,}\) then \(\mathbf{r'(t)} = \mathbf{0}\) (the zero vector). The dot product of \(\mathbf{r(t)}\) and \(\mathbf{r'(t)}\) is:
    \begin{equation*} \mathbf{r(t)} \cdot \mathbf{r'(t)} = \mathbf{c} \cdot \mathbf{0} = 0 \end{equation*}
    Since the dot product is zero, it follows that \(\mathbf{r'(t)}\) is orthogonal to \(\mathbf{r(t)}\) for all \(t\text{.}\)
    🔗
    🔗
    🔗

    Example 2.1.7.

    Find the derivative of the vector function \(\mathbf{r(t)} = \langle t^2+1, \sin(t), e^t \rangle\text{.}\)
    🔗
    Solution.
    The derivative of \(\mathbf{r(t)}\) is given by:
    \begin{equation*} \mathbf{r'(t)} = \frac{d}{dt} \langle t^2+1, \sin(t), e^t \rangle = \langle 2t, \cos(t), e^t \rangle \end{equation*}
    🔗
    🔗
    🔗

    Example 2.1.8.

    Find the derivative of the vector function \(\mathbf{r(t)} = (1+\cos(t))\mathbf{i} + (2+\sin(t))\mathbf{j} + t^2\mathbf{k}\text{.}\)
    🔗
    Solution.
    The derivative of \(\mathbf{r(t)}\) is given by:
    \begin{equation*} \mathbf{r'(t)} = \frac{d}{dt} \langle 1+\cos(t), 2+\sin(t), t^2 \rangle = \langle -\sin(t), \cos(t), 2t \rangle \end{equation*}
    \begin{equation*} \int \mathbf{r(t)} dt = \int \langle t^2, \sin(t), e^t \rangle dt = \langle \frac{t^3}{3}, -\cos(t), e^t \rangle + \mathbf{C} \end{equation*}
    where \(\mathbf{C}\) is a constant vector of integration.
    🔗
    🔗
    🔗

    Example 2.1.9.

    Find the unit tangent vector \(\mathbf{T}(t)\) at the point with the given value of the parameter \(t\text{.}\)
    1. For \(\mathbf{r(t)} = \langle t e^{-t}, 2 \arcsin(t), 2e^t \rangle\) at \(t = 0\text{.}\)
      🔗
      🔗
    2. For \(\mathbf{r(t)} = \langle t^2+3t, t^2+1, 3t+4 \rangle\) at \(t = 1\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. First, we find the derivative of \(\mathbf{r(t)} = \langle t e^{-t}, 2 \arcsin(t), 2e^t \rangle\text{:}\)
      \begin{equation*} \mathbf{r'(t)} = \langle e^{-t} - t e^{-t}, \frac{2}{\sqrt{1-t^2}}, 2e^t \rangle \end{equation*}
      Next, we evaluate \(\mathbf{r'(0)}\text{:}\)
      \begin{equation*} \mathbf{r'(0)} = \langle 1, 2, 2 \rangle \end{equation*}
      Now, we find the magnitude of \(\mathbf{r'(0)}\text{:}\)
      \begin{equation*} |\mathbf{r'(0)}| = \sqrt{1^2 + 2^2 + 2^2} = \sqrt{9} = 3 \end{equation*}
      Finally, we can find the unit tangent vector \(\mathbf{T(0)}\text{:}\)
      \begin{equation*} \mathbf{T(0)} = \frac{\mathbf{r'(0)}}{|\mathbf{r'(0)}|} = \frac{\langle 1, 2, 2 \rangle}{3} = \langle \frac{1}{3}, \frac{2}{3}, \frac{2}{3} \rangle \end{equation*}
      🔗
      🔗
    2. Next, we find the derivative of \(\mathbf{r(t)} = \langle t^2+3t, t^2+1, 3t+4 \rangle\text{:}\)
      \begin{equation*} \mathbf{r'(t)} = \langle 2t+3, 2t, 3 \rangle \end{equation*}
      Next, we evaluate \(\mathbf{r'(1)}\text{:}\)
      \begin{equation*} \mathbf{r'(1)} = \langle 5, 2, 3 \rangle \end{equation*}
      Now, we find the magnitude of \(\mathbf{r'(1)}\text{:}\)
      \begin{equation*} |\mathbf{r'(1)}| = \sqrt{5^2 + 2^2 + 3^2} = \sqrt{38} \end{equation*}
      Finally, we can find the unit tangent vector \(\mathbf{T(1)}\text{:}\)
      \begin{equation*} \mathbf{T(1)} = \frac{\mathbf{r'(1)}}{|\mathbf{r'(1)}|} = \frac{\langle 5, 2, 3 \rangle}{\sqrt{38}} = \langle \frac{5}{\sqrt{38}}, \frac{2}{\sqrt{38}}, \frac{3}{\sqrt{38}} \rangle \end{equation*}
      🔗
      🔗
    🔗
    🔗
    🔗

    Example 2.1.10.

    Find parametric equations for the tangent line to the curve with the given parametric equations at the specified point.
    1. For \(x(t) = t^2 + 1\text{,}\) \(y(t) = \sin(t)\text{,}\) and \(z(t) = e^t\) at \(t = 0\text{.}\)
      🔗
      🔗
    2. \(x=2\cos t\text{,}\) \(y=2\sin t\text{,}\) \(z=4\cos 2t\) at \((\sqrt{3}, 1, 4)\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. First, we find the derivative of the vector function \(\mathbf{r(t)} = \langle t^2 + 1, \sin(t), e^t \rangle\text{:}\)
      \begin{equation*} \mathbf{r'(t)} = \langle 2t, \cos(t), e^t \rangle \end{equation*}
      Next, we evaluate \(\mathbf{r'(0)}\text{:}\)
      \begin{equation*} \mathbf{r'(0)} = \langle 0, 1, 1 \rangle \end{equation*}
      The point on the curve at \(t = 0\) is:
      \begin{equation*} \mathbf{r(0)} = \langle 1, 0, 1 \rangle \end{equation*}
      Therefore, the parametric equations for the tangent line are:
      \begin{equation*} x = 1 + 0t = 1, y = 0 + 1t = t, z = 1 + 1t = t + 1 \end{equation*}
      🔗
      🔗
    2. First, we find the derivative of the vector function \(\mathbf{r(t)} = \langle 2\cos(t), 2\sin(t), 4\cos(2t) \rangle\text{:}\)
      \begin{equation*} \mathbf{r'(t)} = \langle -2\sin(t), 2\cos(t), -8\sin(2t) \rangle \end{equation*}
      Next, we need to find the value of \(t\) that corresponds to the point \((\sqrt{3}, 1, 4)\text{.}\) We can solve for \(t\) using the first two equations:
      \begin{equation*} x(t) = 2\cos(t) = \sqrt{3} \implies t = \frac{\pi}{6} \end{equation*}
      Now we evaluate \(\mathbf{r'(\frac{\pi}{6})}\text{:}\)
      \begin{equation*} \mathbf{r'(\frac{\pi}{6})} = \langle -2\sin(\frac{\pi}{6}), 2\cos(\frac{\pi}{6}), -8\sin(\frac{\pi}{3}) \rangle = \langle -1, \sqrt{3}, -4\sqrt{3} \rangle \end{equation*}
      The point on the curve at \(t = \frac{\pi}{6}\) is:
      \begin{equation*} \mathbf{r(\frac{\pi}{6})} = \langle 2\cos(\frac{\pi}{6}), 2\sin(\frac{\pi}{6}), 4\cos(\frac{\pi}{3}) \rangle = \langle \sqrt{3}, 1, 2 \rangle \end{equation*}
      🔗
      🔗
    🔗
    🔗
    🔗

    Example 2.1.11.

    At what point do the curves \(\mathbf{r_1(t)} = \langle 1+t^2, \sin(t), e^t \rangle\) and \(\mathbf{r_2(t)} = \langle 1+t, \sin(t), e^{2t} \rangle\) intersect? Find the angle between the curves at the point of intersection.
    🔗
    Solution.
    To find the intersection point, we set \(\mathbf{r_1(t)} = \mathbf{r_2(s)}\text{:}\)
    \begin{equation*} \langle 1+t^2, \sin(t), e^{t} \rangle = \langle 1+s, \sin(s), e^{2s} \rangle \end{equation*}
    This gives us the system of equations:
    \begin{equation*} 1+t^2 = 1 + s \quad \Rightarrow t^2 = s \end{equation*}
    \begin{equation*} \sin(t) = \sin(s) \quad \Rightarrow t = s \end{equation*}
    \begin{equation*} e^{t} = e^{2s} \quad \Rightarrow t = 2s \end{equation*}
    🔗
    From the second equation, we have \(t = s\text{.}\) Substituting this into the first equation gives us \(t^2 = t\text{,}\) which has solutions \(t = 0\) or \(t = 1\text{.}\) Substituting \(t = 0\) into the third equation gives us \(0 = 2(0)\text{,}\) which is true. Substituting \(t = 1\) into the third equation gives us \(1 = 2(1)\text{,}\) which is false. Therefore, the curves intersect at \(t = 0\) and \(s = 0\text{.}\) The intersection point is \(\mathbf{r_1(0)} = \langle 1, 0, 1 \rangle\text{.}\)
    🔗
    To find the angle between the curves at the point of intersection, we need to find the tangent vectors of the curves at \(t = 0\) and \(s = 0\text{:}\)
    \begin{equation*} \mathbf{r_1'(t)} = \langle 2t, \cos(t), e^t \rangle \quad \Rightarrow \mathbf{r_1'(0)} = \langle 0, 1, 1 \rangle \end{equation*}
    \begin{equation*} \mathbf{r_2'(s)} = \langle 1, \cos(s), 2e^{2s} \rangle \quad \Rightarrow \mathbf{r_2'(0)} = \langle 1, 1, 2 \rangle \end{equation*}
    🔗
    Compute the angle \(\theta\) using the dot product:
    \begin{equation*} \cos(\theta) = \frac{\mathbf{r}_1'(0) \cdot \mathbf{r}_2'(0)}{\Vert{}\mathbf{r}_1'(0)\Vert{}\,\Vert{}\mathbf{r}_2'(0)\Vert{}} = \frac{(0)(1) + (1)(1) + (1)(2)}{\sqrt{0^2 + 1^2 + 1^2}\sqrt{1^2 + 1^2 + 2^2}} = \frac{3}{\sqrt{2}\sqrt{6}} = \frac{3}{\sqrt{12}} = \frac{\sqrt{3}}{2} \end{equation*}
    \begin{equation*} \therefore \theta = \arccos\!\left(\frac{\sqrt{3}}{2}\right) = \frac{\pi}{6} \text{ radians } (\text{ or, } 30^\circ) \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Subsection 2.1.2 Integration of Vector Functions

    The integral of a vector function is defined similarly to the integral of a real-valued function. If \(\mathbf{r(t)}\) is a vector function, then its integral is given by:
    \begin{equation*} \int \mathbf{r(t)} dt = \mathbf{R(t)} + \mathbf{C} \end{equation*}
    where \(\mathbf{R(t)}\) is the antiderivative of \(\mathbf{r(t)}\) and \(\mathbf{C}\) is a constant vector of integration. The integral represents the accumulation of the vector function over the interval of integration, and it can be used to find the position vector of a particle given its velocity vector, or to compute the area under a curve in three-dimensional space.
    🔗
    The definite integral of a vector function \(\mathbf{r(t)}\) from \(a\) to \(b\) is given by:
    \begin{equation*} \int_{a}^{b} \mathbf{r(t)} dt = \left(\int_{a}^{b} \mathbf{f(t)} dt\right) \mathbf{i} + \left(\int_{a}^{b} \mathbf{g(t)} dt\right) \mathbf{j} + \left(\int_{a}^{b} \mathbf{h(t)} dt\right) \mathbf{k} = \mathbf{R(b)} - \mathbf{R(a)} \end{equation*}
    where \(\mathbf{R(t)}\) is the antiderivative of \(\mathbf{r(t)}\text{.}\) This represents the net change in the vector function over the interval \([a, b]\text{.}\)
    🔗

    Example 2.1.12.

    Find the integral of the vector function \(\mathbf{r(t)} = \langle t^2, \sin(t), e^t \rangle\text{.}\)
    🔗
    Solution.
    The integral of \(\mathbf{r(t)}\) is given by:
    \begin{equation*} \int \mathbf{r(t)} dt = \int \langle t^2, \sin(t), e^t \rangle dt = \langle \frac{t^3}{3}, -\cos(t), e^t \rangle + \mathbf{C} \end{equation*}
    where \(\mathbf{C}\) is a constant vector of integration.
    🔗
    🔗
    🔗

    Example 2.1.13.

    Compute the definite integral of the vector function \(\mathbf{r(t)} = \langle t^2, \sin(t), e^t \rangle\) from \(0\) to \(1\text{.}\)
    🔗
    Solution.
    The definite integral is given by:
    \begin{equation*} \int_{0}^{1} \mathbf{r(t)} dt = \int_{0}^{1} \langle t^2, \sin(t), e^t \rangle dt = \langle \frac{1}{3}, 1 - \cos(1), e - 1 \rangle \end{equation*}
    This represents the net change in the vector function over the interval \([0, 1]\text{.}\)
    🔗
    🔗
    🔗

    Example 2.1.14.

    Find the integral of the vector function \(\mathbf{r(t)} = 2\cos(t)\mathbf{i} + \sin(t)\mathbf{j} + 2t\mathbf{k}\text{.}\) If \(\mathbf{r(0)} = \langle 1, 0, 0 \rangle\text{,}\) find \(\mathbf{r(t)}\text{.}\)
    🔗
    Solution.
    The integral of \(\mathbf{r(t)}\) is given by:
    \begin{equation*} \int \mathbf{r(t)} dt = \int \langle 2\cos(t), \sin(t), 2t \rangle dt = \langle 2\sin(t), -\cos(t), t^2 \rangle + \mathbf{C} \end{equation*}
    where \(\mathbf{C}\) is a constant vector of integration.
    🔗
    To find \(\mathbf{C}\text{,}\) we use the initial condition \(\mathbf{r(0)} = \langle 1, 0, 0 \rangle\text{:}\)
    \begin{equation*} \mathbf{r(0)} = \langle 2\sin(0), -\cos(0), 0^2 \rangle + \mathbf{C} = \langle 0, -1, 0 \rangle + \mathbf{C} = \langle 1, 0, 0 \rangle \end{equation*}
    This gives us \(\mathbf{C} = \langle 1, 1, 0 \rangle\text{.}\) Therefore, the vector function is:
    \begin{equation*} \mathbf{r(t)} = \langle 2\sin(t) + 1, -\cos(t) + 1, t^2 \rangle \end{equation*}
    🔗
    🔗
    🔗

    Example 2.1.15.

    Evaluate the definite integral of the vector function \(\mathbf{r(t)} = t\mathbf{i} + t^2\mathbf{j} - 3t^3\mathbf{k}\) from \(0\) to \(1\text{.}\)
    🔗
    Solution.
    The definite integral is given by:
    \begin{equation*} \int_{0}^{1} \mathbf{r(t)} dt = \int_{0}^{1} \langle t, t^2, -3t^3 \rangle dt = \langle \frac{1}{2}, \frac{1}{3}, -\frac{3}{4} \rangle \end{equation*}
    This represents the net change in the vector function over the interval \([0, 1]\text{.}\)
    🔗
    🔗
    🔗

    Example 2.1.16.

    Find the integral of the vector function \(\mathbf{r(t)} = 2\cos(t)\mathbf{i} + \sin(t)\mathbf{j} + 2t\mathbf{k}\text{.}\) If \(\mathbf{r(0)} = \langle 1, 0, 0 \rangle\text{,}\) find \(\mathbf{r(t)}\text{.}\)
    🔗
    Solution.
    The integral of \(\mathbf{r(t)}\) is given by:
    \begin{equation*} \int \mathbf{r(t)} dt = \int \langle 2\cos(t), \sin(t), 2t \rangle dt = \langle 2\sin(t), -\cos(t), t^2 \rangle + \mathbf{C} \end{equation*}
    where \(\mathbf{C}\) is a constant vector of integration.
    🔗
    To find \(\mathbf{C}\text{,}\) we use the initial condition \(\mathbf{r(0)} = \langle 1, 0, 0 \rangle\text{:}\)
    \begin{equation*} \mathbf{r(0)} = \langle 2\sin(0), -\cos(0), 0^2 \rangle + \mathbf{C} = \langle 0, -1, 0 \rangle + \mathbf{C} = \langle 1, 0, 0 \rangle \end{equation*}
    This gives us \(\mathbf{C} = \langle 1, 1, 0 \rangle\text{.}\) Therefore, the vector function is:
    \begin{equation*} \mathbf{r(t)} = \langle 2\sin(t) + 1, -\cos(t) + 1, t^2 \rangle \end{equation*}
    🔗
    🔗
    🔗

    Example 2.1.17.

    Evaluate the definite integral of the vector function \(\mathbf{r(t)} = \langle t^2, \sin(t), e^t \rangle\) from \(0\) to \(1\text{.}\)
    🔗
    Solution.
    The definite integral is given by:
    \begin{equation*} \int_{0}^{1} \mathbf{r(t)} dt = \int_{0}^{1} \langle t^2, \sin(t), e^t \rangle dt = \langle \frac{1}{3}, 1 - \cos(1), e - 1 \rangle \end{equation*}
    This represents the net change in the vector function over the interval \([0, 1]\text{.}\)
    🔗
    🔗
    🔗

    Example 2.1.18.

    Find \(\mathbf{r(t)} \text{.}\) If \(\mathbf{r'(t)} = \langle 2\cos(t), \sin(t), 2t \rangle\) and \(\mathbf{r(0)} = \langle 1, 0, 0 \rangle\text{.}\)
    🔗
    Solution.
    The integral of \(\mathbf{r'(t)}\) is given by:
    \begin{equation*} \int \mathbf{r'(t)} dt = \int \langle 2\cos(t), \sin(t), 2t \rangle dt = \langle 2\sin(t), -\cos(t), t^2 \rangle + \mathbf{C} \end{equation*}
    where \(\mathbf{C}\) is a constant vector of integration.
    🔗
    To find \(\mathbf{C}\text{,}\) we use the initial condition \(\mathbf{r(0)} = \langle 1, 0, 0 \rangle\text{:}\)
    \begin{equation*} \mathbf{r(0)} = \langle 2\sin(0), -\cos(0), 0^2 \rangle + \mathbf{C} = \langle 0, -1, 0 \rangle + \mathbf{C} = \langle 1, 0, 0 \rangle \end{equation*}
    This gives us \(\mathbf{C} = \langle 1, 1, 0 \rangle\text{.}\) Therefore, the vector function is:
    \begin{equation*} \mathbf{r(t)} = \langle 2\sin(t) + 1, -\cos(t) + 1, t^2 \rangle \end{equation*}

    Example 2.1.19.

    If \(\mathbf{u(t)} = \langle \sin(t), \cos(t), t \rangle\) and \(\mathbf{v(t)} = \langle t, \cos(t), \sin(t) \rangle\text{,}\) find \(\frac{d}{dt} \left[\mathbf{u(t)}\cdot \mathbf{v(t)} \right]\text{.}\)
    🔗
    Solution.
    The derivative of the dot product is given by:
    \begin{equation*} \frac{d}{dt} \left[\mathbf{u(t)}\cdot \mathbf{v(t)} \right] = \mathbf{u'(t)}\cdot \mathbf{v(t)} + \mathbf{u(t)}\cdot \mathbf{v'(t)} \end{equation*}
    🔗
    First, we find the derivatives:
    \begin{equation*} \mathbf{u'(t)} = \langle \cos(t), -\sin(t), 1 \rangle \end{equation*}
    \begin{equation*} \mathbf{v'(t)} = \langle 1, -\sin(t), \cos(t) \rangle \end{equation*}
    🔗
    Then, we compute the dot products:
    \begin{equation*} \mathbf{u'(t)}\cdot \mathbf{v(t)} = \cos(t) \cdot t + (-\sin(t)) \cdot \cos(t) + 1 \cdot \sin(t) = t\cos(t) - \sin(t)\cos(t) + \sin(t) \end{equation*}
    \begin{equation*} \mathbf{u(t)}\cdot \mathbf{v'(t)} = \sin(t) \cdot 1 + \cos(t) \cdot (-\sin(t)) + t \cdot \cos(t) = \sin(t) - \cos(t)\sin(t) + t\cos(t) \end{equation*}
    🔗
    Adding these together:
    \begin{equation*} \frac{d}{dt} \left[\mathbf{u(t)}\cdot \mathbf{v(t)} \right] = t\cos(t) - \sin(t)\cos(t) + \sin(t) + \sin(t) - \cos(t)\sin(t) + t\cos(t) = 2t\cos(t) - 2\sin(t)\cos(t) + 2\sin(t) \end{equation*}
