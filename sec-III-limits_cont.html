    Section 3.2 Limits and Continuity

    In this section, we will explore the concepts of limits and continuity for functions of two variables. We will discuss how to evaluate limits, determine the existence of limits, and analyze the continuity of functions in two dimensions.
    🔗
    Let \(f\) be a function of two variables whose domain \(D\) includes points arbitrarily close to \((a, b)\text{.}\) Then we say that the limit of \(f(x, y)\) as \((x, y)\) approaches \((a, b)\) is \(L\) and we write
    \begin{equation*} \lim_{(x, y) \to (a, b)} f(x, y) = L \end{equation*}
    if for every number \(\epsilon \gt 0\) there exists a number \(\delta \gt 0\) such that
    \begin{equation*} 0 \lt \sqrt{(x - a)^2 + (y - b)^2} \lt \delta \implies |f(x, y) - L| \lt \epsilon \end{equation*}
    whenever \((x, y)\) is in the domain \(D\) of \(f\text{.}\)
    🔗

    Example 3.2.1.

    Find the limit of \(f(x, y) = \frac{x^2 + y^2}{x^2 + y^2 + 1}\) as \((x, y)\) approaches \((0, 0)\text{.}\)
    🔗
    Solution.
    As \((x, y)\) approaches \((0, 0)\text{,}\) the numerator \(x^2 + y^2\) approaches 0, and the denominator \(x^2 + y^2 + 1\) approaches 1. Therefore,
    \begin{equation*} \lim_{(x, y) \to (0, 0)} f(x, y) = \lim_{(x, y) \to (0, 0)} \frac{x^2 + y^2}{x^2 + y^2 + 1} = \frac{0}{1} = 0 \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.2.

    Determine if the function \(f(x, y) = \frac{xy}{x^2 + y^2}\) has a limit as \((x, y)\) approaches \((0, 0)\text{.}\)
    🔗
    Solution.
    To check if the limit exists, we can approach \((0, 0)\) along different paths. For example, along the line \(y = mx\text{,}\) we have:
    \begin{equation*} f(x, mx) = \frac{x(mx)}{x^2 + (mx)^2} = \frac{mx^2}{x^2(1 + m^2)} = \frac{m}{1 + m^2} \end{equation*}
    As \(x\) approaches 0, this expression approaches \(\frac{m}{1 + m^2}\text{,}\) which depends on the slope \(m\text{.}\) Since the limit depends on the path taken, the limit does not exist.
    🔗
    🔗
    🔗

    Example 3.2.3.

    Show that \(\lim_{(x, y) \to (0, 0)} \frac{x^2 - y^2}{x^2 + y^2}\) does not exist.
    🔗
    Solution.
    We can approach \((0, 0)\) along the line \(y = x\) and the line \(y = -x\text{.}\) Along \(y = x\text{,}\) we have:
    \begin{equation*} f(x, x) = \frac{x^2 - x^2}{x^2 + x^2} = \frac{0}{2x^2} = 0 \end{equation*}
    Along \(y = -x\text{,}\) we have:
    \begin{equation*} f(x, -x) = \frac{x^2 - (-x)^2}{x^2 + (-x)^2} = \frac{x^2 - x^2}{x^2 + x^2} = \frac{0}{2x^2} = 0 \end{equation*}
    However, if we approach along the line \(y = 0\text{,}\) we have:
    \begin{equation*} f(x, 0) = \frac{x^2 - 0}{x^2 + 0} = 1 \end{equation*}
    Since the limit depends on the path taken, the limit does not exist.
    🔗
    🔗
    🔗

    Example 3.2.4.

    If \(f(x, y) = \frac{xy}{x^2 + y^2}\text{,}\) does \(\lim_{(x, y) \to (0, 0)} f(x, y)\) exist?
    🔗
    Solution.
    To determine if the limit exists, we can approach \((0, 0)\) along different paths. For example, along the line \(y = mx\text{,}\) we have:
    \begin{equation*} f(x, mx) = \frac{x(mx)}{x^2 + (mx)^2} = \frac{mx^2}{x^2(1 + m^2)} = \frac{m}{1 + m^2} \end{equation*}
    As \(x\) approaches 0, this expression approaches \(\frac{m}{1 + m^2}\text{,}\) which depends on the slope \(m\text{.}\) Since the limit depends on the path taken, the limit does not exist.
    🔗
    🔗
    🔗

    Example 3.2.5.

    Find the limit of \(f(x, y) = \frac{3x^2 y}{x^2 + y^2}\) as \((x, y) \to (0, 0)\text{.}\)
    🔗
    Solution.
    To find the limit, we can approach \((0, 0)\) along different paths. For example, along the line \(y = mx\text{,}\) we have:
    \begin{equation*} f(x, mx) = \frac{3x^2(mx)}{x^2 + (mx)^2} = \frac{3mx^3}{x^2(1 + m^2)} = \frac{3mx}{1 + m^2} \end{equation*}
    As \(x\) approaches 0, this expression approaches 0. Since the limit is the same regardless of the path taken, the limit exists and equals 0.
    🔗
    🔗

    Subsection 3.2.1 Continuity

    A function \(f\) of two variables is called continuous at \((a, b)\) if
    \begin{equation*} \lim_{(x, y) \to (a, b)} f(x, y) = f(a, b) \end{equation*}
    🔗

    Example 3.2.6.

    Determine if the function \(f(x, y) = \frac{x^2 + y^2}{\sqrt{x^2 + y^2 + 1}}\) is continuous at \((0, 0)\text{.}\)
    🔗
    Solution.
    To check continuity at \((0, 0)\text{,}\) we need to verify that:
    \begin{equation*} \lim_{(x, y) \to (0, 0)} f(x, y) = f(0, 0) \end{equation*}
    We have:
    \begin{equation*} f(0, 0) = \frac{0 + 0}{\sqrt{0 + 0 + 1}} = 0 \end{equation*}
    Now, we compute the limit:
    \begin{equation*} \lim_{(x, y) \to (0, 0)} f(x, y) = \lim_{(x, y) \to (0, 0)} \frac{x^2 + y^2}{\sqrt{x^2 + y^2 + 1}} = 0 \end{equation*}
    Since the limit equals the function value at \((0, 0)\text{,}\) the function is continuous at that point.
    🔗
    🔗
    🔗

    Example 3.2.7.

    Evaluate
    \begin{equation*} \lim_{(x, y) \to (1, 2)} (x^2y^3 - x^3y^2 + 3x + 2y) \end{equation*}
    🔗
    Solution.
    Since the function is a polynomial in \(x\) and \(y\text{,}\) it is continuous everywhere. Therefore, we can directly substitute \((1, 2)\) into the function:
    \begin{equation*} f(1, 2) = (1^2)(2^3) - (1^3)(2^2) + 3(1) + 2(2) = 8 - 4 + 3 + 4 = 11 \end{equation*}
    Thus, the limit is:
    \begin{equation*} \lim_{(x, y) \to (1, 2)} (x^2y^3 - x^3y^2 + 3x + 2y) = 11 \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.8.

    Determine if the function \(f(x, y) = \frac{xy}{x^2 + y^2}\) is continuous at \((0, 0)\text{.}\)
    🔗
    Solution.
    To check continuity at \((0, 0)\text{,}\) we need to verify that:
    \begin{equation*} \lim_{(x, y) \to (0, 0)} f(x, y) = f(0, 0) \end{equation*}
    However, the function is not defined at \((0, 0)\) since the denominator becomes zero. Therefore, the function is not continuous at that point.
    🔗
    🔗
    🔗

    Example 3.2.9.

    Where is the function \(f(x, y) = \frac{x^2 - y^2}{x^2 + y^2}\) continuous?
    🔗
    Solution.
    The function \(f(x, y) = \frac{x^2 - y^2}{x^2 + y^2}\) is continuous everywhere except at the origin \((0, 0)\text{,}\) where it is not defined.

    Subsection 3.2.2 Partial Derivatives

    In this section, we will explore the concept of partial derivatives for functions of two variables. We will discuss how to compute partial derivatives, interpret their meaning, and apply them to various problems in multivariable calculus. If \(z = f(x, y)\text{,}\) we write
    \begin{equation*} fx(x, y) = fx = \partial f/\partial x = \frac{\partial z}{\partial x} \end{equation*}
    \begin{equation*} \text{and} \quad fy(x, y) = fy = \partial f/\partial y = \frac{\partial z}{\partial y} \end{equation*}
    🔗

    Example 3.2.10.

    Find the partial derivatives of \(f(x, y) = x^2y + 3xy^2\text{.}\)
    🔗
    Solution.
    To find the partial derivative with respect to \(x\text{,}\) we treat \(y\) as a constant:
    \begin{equation*} fx(x, y) = \frac{\partial}{\partial x}(x^2y + 3xy^2) = 2xy + 3y^2 \end{equation*}
    To find the partial derivative with respect to \(y\text{,}\) we treat \(x\) as a constant:
    \begin{equation*} fy(x, y) = \frac{\partial}{\partial y}(x^2y + 3xy^2) = x^2 + 6xy \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.11.

    Find the partial derivatives of \(f(x, y) = e^{xy} + \sin(x + y)\text{.}\)
    🔗
    Solution.
    To find the partial derivative with respect to \(x\text{,}\) we treat \(y\) as a constant:
    \begin{equation*} fx(x, y) = \frac{\partial}{\partial x}(e^{xy} + \sin(x + y)) = ye^{xy} + \cos(x + y) \end{equation*}
    To find the partial derivative with respect to \(y\text{,}\) we treat \(x\) as a constant:
    \begin{equation*} fy(x, y) = \frac{\partial}{\partial y}(e^{xy} + \sin(x + y)) = xe^{xy} + \cos(x + y) \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.12.

    Find the partial derivatives of \(f(x, y) = \ln(x^2 + y^2)\text{.}\)
    🔗
    Solution.
    To find the partial derivative with respect to \(x\text{,}\) we treat \(y\) as a constant:
    \begin{equation*} fx(x, y) = \frac{\partial}{\partial x}(\ln(x^2 + y^2)) = \frac{2x}{x^2 + y^2} \end{equation*}
    To find the partial derivative with respect to \(y\text{,}\) we treat \(x\) as a constant:
    \begin{equation*} fy(x, y) = \frac{\partial}{\partial y}(\ln(x^2 + y^2)) = \frac{2y}{x^2 + y^2} \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.13.

    If \(f(x, y) = x^3 + x^2y^3 - 2y^2\text{,}\) find \(f_x(2, 1)\) and \(f_y(2, 1)\text{.}\)
    🔗
    Solution.
    To find the partial derivative with respect to \(x\text{,}\) we treat \(y\) as a constant:
    \begin{equation*} fx(x, y) = \frac{\partial}{\partial x}(x^3 + x^2y^3 - 2y^2) = 3x^2 + 2xy^3 \end{equation*}
    also, we can evaluate \(f_x(2, 1)\text{:}\)
    \begin{equation*} f_x(2, 1) = 3(2^2) + 2(2)(1^3) = 12 + 4 = 16 \end{equation*}
    To find the partial derivative with respect to \(y\text{,}\) we treat \(x\) as a constant:
    \begin{equation*} fy(x, y) = \frac{\partial}{\partial y}(x^3 + x^2y^3 - 2y^2) = 3x^2y^2 - 4y \end{equation*}
    and we can evaluate \(f_y(2, 1)\text{:}\)
    \begin{equation*} f_y(2, 1) = 3(2^2)(1^2) - 4(1) = 12 - 4 = 8 \end{equation*}
    🔗
    🔗
    🔗

    Example 3.2.14.

    If \(f(x, y) = 4 - x^2 - 2y^2\text{,}\) find \(f_x(1, 1)\) and \(f_y(1, 1)\) and interpret these numbers as slopes.
    🔗
    Solution.
    To find the partial derivative with respect to \(x\text{,}\) we treat \(y\) as a constant:
    \begin{equation*} fx(x, y) = \frac{\partial}{\partial x}(4 - x^2 - 2y^2) = -2x \end{equation*}
    also, we can evaluate \(f_x(1, 1)\text{:}\)
    \begin{equation*} f_x(1, 1) = -2(1) = -2 \end{equation*}
    To find the partial derivative with respect to \(y\text{,}\) we treat \(x\) as a constant:
    \begin{equation*} fy(x, y) = \frac{\partial}{\partial y}(4 - x^2 - 2y^2) = -4y \end{equation*}
    and we can evaluate \(f_y(1, 1)\text{:}\)
    \begin{equation*} f_y(1, 1) = -4(1) = -4 \end{equation*}
    🔗
    The graph of \(f(x, y) = 4 - x^2 - 2y^2\) is a downward-opening paraboloid. The value \(f_x(1, 1) = -2\) represents the slope of the tangent line to the curve obtained by intersecting the surface with the plane \(y = 1\) at the point \((1, 1, f(1, 1))\text{.}\) The value \(f_y(1, 1) = -4\) represents the slope of the tangent line to the curve obtained by intersecting the surface with the plane \(x = 1\) at the point \((1, 1, f(1, 1))\text{.}\) Both slopes are negative, indicating that the surface is decreasing in both the \(x\) and \(y\) directions at the point \((1, 1)\text{.}\)
    🔗
    🔗
    🔗

    Example 3.2.15.

    Find the second partial derivatives of \(f(x,y) = x^3+x^2y^3-5y^2\)
    🔗
    Solution.
    \begin{equation*} f_x = 3x^2+2xy^3 \quad \text{ and } f_y = 3x^2y^2-10y \end{equation*}
    \begin{equation*} f_{xx} = \frac{\partial }{\partial x} f_x = 6x+2y^3 \end{equation*}
    \begin{equation*} f_{xy} = \frac{\partial }{\partial y} f_x = 6xy^2 \end{equation*}
    \begin{equation*} f_{yx} = \frac{\partial }{\partial x} f_y = 6xy^2 \end{equation*}
    \begin{equation*} f_{yy} = \frac{\partial }{\partial y} f_y = 6x^2y-10 \end{equation*}
    🔗
    The mixed partial derivatives \(f_{xy}\) and \(f_{yx}\) are equal for most functions.
